Application Android (APK)

Le dossier mobile/ du projet contient le code source complet de l'application Android (WebView + site embarqué + support hors ligne).

  1. Téléchargez le ZIP de la plateforme depuis votre espace de travail.
  2. Ouvrez le dossier mobile/ dans Android Studio (Build ▸ Build APK) ou lancez ./gradlew assembleDebug.
  3. Installez l'APK app/build/outputs/apk/debug/app-debug.apk sur les téléphones de l'équipe et des livreurs.
  4. Pour publier sur le Play Store : ./gradlew assembleRelease avec votre clé de signature, puis envoi du fichier .aab.

Le guide complet se trouve dans GUIDE-INSTALLATION.md à la racine du projet.

Avis clients

Mode d'emploi rapide

  1. Réception des commandes : chaque commande arrivée sur WhatsApp est aussi enregistrée ici (onglet « Commandes »). Une nouvelle commande apparaît avec le statut « Nouvelle ».
  2. Faire avancer une commande : utilisez les boutons de la colonne « Actions » — Confirmer → En préparation → En livraison → Livrée.
  3. Modifier le menu : onglet « Menu & prix », changez les textes et prix puis cliquez sur « Enregistrer le menu ». Les modifications sont visibles immédiatement sur le site.
  4. Changer le numéro WhatsApp : onglet « Paramètres », champ « Numéro WhatsApp » au format international sans espaces (ex. 24174000000).
  5. Suivre une commande pour un client : le client entre son numéro (RT-…) et son téléphone sur la page « Suivre ma commande » du site.
  6. Alertes : cliquez sur « 🔔 Alertes » pour autoriser les notifications du navigateur. Le tableau de bord se rafraîchit automatiquement toutes les 30 secondes.

Sauvegardes

Les données sont stockées dans le dossier data/ : menu.json (carte), settings.json (paramètres), orders.json (commandes). Copiez ce dossier régulièrement (ou lancez npm run backup).
